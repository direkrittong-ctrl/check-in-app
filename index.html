ข้อควรทราบเพิ่มเติมสำหรับการใช้งานระบบ GPS การใช้งานโปรโตคอล HTTPS: เบราว์เซอร์ยุคใหม่ (เช่น Chrome, Safari, iOS) จะไม่อนุญาตให้ใช้ Geolocation API บนเว็บที่ไม่ปลอดภัย ดังนั้นต้องโฮสต์ไฟล์ผ่าน HTTPS เท่านั้น (เช่น GitHub Pages หรือ Vercel ที่มี SSL) การระบุพิกัดห้องเรียน: สามารถนำพิกัดละติจูดและลองจิจูดจริงของห้อง 2101 และ 2102 ไปใส่ไว้ในอ็อบเจกต์ ROOM_LOCATIONS ที่ส่วน JavaScript เพื่อเพิ่มความแม่นยำในการวัดระยะทางได้เลยครับ
